Configurar Google Calendar

Para conectar con tu Google Calendar real necesitas una API Key de Google. Sigue estos pasos:

  1. Ve a console.cloud.google.com
  2. Crea un proyecto → Habilita "Google Calendar API"
  3. Credenciales → Crear credencial → API Key
  4. Pega aquí tu API Key y el ID de tu calendario
